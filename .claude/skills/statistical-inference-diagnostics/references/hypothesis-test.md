# 仮説検定の必須セット（主旨: 安易に検定しない）

短縮名: `htest`（図の保存先 `outputs/diagnostics/<YYYYMMDD-HHMM>_htest/`）。報告の書式と判定表はルーター SKILL.md の「出力と報告」に従う。

既定では仮説検定を行わない。群間の違いは、まず可視化と推定（点推定 + 95% 信頼区間 + 効果量）で答える。
p 値は答えの一部ではなく、二値の意思決定が必要なときにだけ足す補助情報である。
検定を行う場合は、事前に決めた仮説 1 つに対して 1 回だけ行う。

## 適用範囲

- 扱う: 2 群・多群の比較（平均・比率・分布）、対応あり比較、分割表、ANOVA、多重比較の扱い
- 扱わない: ランダム化実験の分析 → `causal-inference-diagnostics`（`references/ab-test.md`） / 回帰係数の推論 → `references/ols.md`・`references/glm.md` / 全数データ（母集団そのもの）→ 検定は不要。記述で答える

## 検定してよい条件（すべて満たすときだけ。統計学一般の必須条件ではなく、この skill の運用方針）

1. 検定の前に仮説と主要指標が 1 つ決まっている
2. 結果が二値の意思決定（採用する / しない）に直結する
3. 比較する群・指標・期間がデータを見る前に決まっている

満たさない場合: 群別の分布図と、差の点推定 + 95% CI + 効果量を出し、「これは探索であり検定は行っていない」と報告に明記する。
どうしても複数検定が必要なら、主要仮説 1 つを宣言し、残りは「探索的」と明記して BH（Benjamini-Hochberg）補正をかけ、補正の対象範囲（どの比較の族か）を書く。

## ライブラリ

- pingouin（`ttest` / `mwu` / `anova` / `pairwise_tests` が効果量と CI を一括で返すので優先）、scipy.stats、statsmodels（`multipletests`）
- pingouin 未導入なら `uv add pingouin`（scipy のみなら Cohen's d と CI をブートストラップで自前計算）

## 必ず出す図

- 連続量: 群別の分布（箱ひげ + 個票 strip / swarm、n を併記） — 分布の重なりが目視できること。重なりが大きいのに「差あり」と書かない。個票は 1 群 1,000 点が上限（swarm は超えると描画が破綻し、strip は塗り潰しになる）。超えるなら ECDF かヒストの重ね描きに替える
- 比率・分割表: 群別の比率と 95% CI の棒（セルの n を併記）。3×3 以上なら Pearson 残差のヒートマップ — どのセルが期待度数から離れているかが読めれば合格
- 対応ありなら個体ごとの前後を結んだ線（スパゲッティ） — 大半の線が同方向なら効果が一貫
- 効果量と 95% CI のフォレストプロット（比較が複数ある場合。0 と最小重要差に縦破線） — CI が最小重要差を含むかで判断
- 二元配置 ANOVA なら交互作用プロット — 線が平行なら交互作用なし

## 必ず出す値

| 項目 | 合格基準 | 備考 |
|---|---|---|
| 差の点推定 + 95% CI | 必ず出す | p 値より先に書く。「検出できた最小効果量」を CI 幅で議論する |
| 効果量（Cohen's d / Cramér's V / η²）+ CI | 必ず出す | 小 0.2 / 中 0.5 / 大 0.8 の目安を併記（d の場合） |
| 群ごとの n と記述統計 | 必ず出す | 平均・SD・中央値・四分位 |
| 検定を行ったか / 行っていないか | 明記する | 行った場合は事前仮説を 1 行で |
| p 値 | **1 つだけ**（事前仮説に対して） | 複数出すなら BH 補正と補正の対象範囲を明記 |
| 等分散の扱い | 最初から Welch | 等分散検定で検定を選ばない |

取得例（`a`, `b` は 2 群の値の配列）:

```python
import numpy as np
import pingouin as pg
import polars as pl
# 既定は推定: 群別 n・記述統計 → 差の点推定 + 95% CI + 効果量。検定は事前仮説 1 つに 1 回だけ
# 群の長さが違ってよいよう縦持ちにする。pingouin には配列（a, b）をそのまま渡す
desc = (pl.DataFrame({"群": ["a"] * len(a) + ["b"] * len(b), "値": np.concatenate([a, b])})
        .group_by("群").agg(n=pl.len(), mean=pl.col("値").mean(), sd=pl.col("値").std(),
                            median=pl.col("値").median(),
                            q1=pl.col("値").quantile(0.25, interpolation="linear"),
                            q3=pl.col("値").quantile(0.75, interpolation="linear")))
res = pg.ttest(a, b, correction=True)  # Welch を最初から。CI95, p_val を 1 行で返す（pingouin ≥ 0.6 の列名）
diff, diff_ci = np.mean(a) - np.mean(b), res["CI95"].iloc[0]  # 差の点推定と 95% CI（p 値より先に書く）
d = pg.compute_effsize(a, b, eftype="cohen")  # 符号付き（a − b）。ttest の cohen_d は絶対値で、CI と向きが合わない
d_ci = pg.compute_bootci(a, b, func="cohen", n_boot=2000, seed=0)  # 効果量の 95% CI（符号付き）
```

## 落とし穴

- 複数の変数・部分集団・時点を片端から検定しない。有意になるまで群分け・期間・指標を変えない
- 正規性・等分散の検定をしてから本検定を選ぶ二段構えをしない（事前検定の結果に条件づけると、本検定の第一種の誤りが名目どおりにならない）。等分散は仮定せず最初から Welch。非正規が気になるなら、使う手法（順位ベース・ブートストラップ）をデータを見る前に決める
  ```python
  # NG: 正規性検定の結果で検定を切り替える
  test = ttest_ind if shapiro(a).pvalue > 0.05 else mannwhitneyu
  ```
- 事後検出力（observed power）を報告しない（p 値の単調変換で情報がない）。Shapiro-Wilk は n 大で些細な非正規性でも棄却される。Q-Q 目視を主に
- n が大きいだけで有意になった些末な差を「差がある」と書かない。効果量で判断する
- p 値を出さなくても、多数の比較から差の大きいものだけを選んで報告すれば、選択と多重性の問題は残る。比較したものはすべて並べ、探索であることを明記する
- Cohen の目安（0.2 / 0.5 / 0.8）を最小重要差（MID）の代わりにしない。観測された差の大きさと、実務上意味のある差は別で、MID が未定義なら「実務上意味がある」とは書かずに `確認` へ回す
- 非有意を「差がない」と書かない。Mann-Whitney は「中央値の差」の検定ではない（分布の位置ずれ）
